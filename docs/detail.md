## 1. 職務要約

AWS / GCP のクラウド環境について、現状調査、改善優先度の整理、構成設計・実装、監視・IAM・バックアップ・障害対応手順の整備を担当します。開発担当者や CTO と改善方針を調整し、設計判断の根拠・構成・操作手順を文書に残す支援をしてきました。

**代表実績**

- **GCP の既存環境改善：** Cloud Run / Cloud SQL / Cloud Storage を中心に構成見直し・IAM・バックアップ・監視を整備。費用最適化に向けた利用状況調査・不要リソースの確認を担当
- **AWS の初期基盤構築：** 睡眠解析サービス向け非同期処理の基盤をサンドボックス・開発環境に設計・実装。Grafana 監視環境の PoC、構成・操作手順の文書化、事前合意した引き継ぎ資料の作成・共有を完了
- **SLO 定義支援：** Datadog モニター全 55 件を棚卸し・分類。AWS ALB ログからサービス稼働率 SLI の実測ベースラインを算出し、Datadog 計測値との整合性を検証

**これまでの担当領域：** IoT データ基盤の設計・実装・運用（Luup）、約 200 サービスの AWS 移行における CCoE・技術相談・設計レビュー（BIGLOBE）、通信インフラの開発検証（ソフトバンク）。情シス・生成 AI の支援経験も後段に記載しています。

## 5. フリーランスとしての支援実績

### ■ [業務委託] 自治体・法人向けキャッシュレス決済／ポイント基盤 SRE・SLO定義支援

| | |
|:---|:---|
| **期間** | 2026 年 7 月〜2026 年 9 月 |
| **技術スタック** | Datadog, AWS, SLI/SLO, GitHub, Markdown/HTML |
| **体制** | SRE チームにコントラクターとして参画。上長・プロジェクトオーナーと連携 |
| **役割** | SRE、SLO 定義資料作成、Datadog モニター監査・分類、SLI 実測値の算出・検証 |
| **規模** | 自治体・法人向けキャッシュレス決済／ポイント基盤プラットフォーム |

#### 概要

自治体や企業向けにキャッシュレス決済・ポイント基盤サービスを提供する企業の SRE チームに、コントラクターとして SLO（サービスレベル目標）定義プロジェクトで参画。既存の Datadog 監視環境（モニター全 55 件）を棚卸しし、サービス稼働・インフラ・DB・外部依存・業務系といった観点で分類・整理したうえで、通知経路の不整合や Priority 設定のばらつきなど改善が必要な項目を洗い出しました。

あわせて、AWS ALB ログの分析によるサービス稼働率の SLI（実測ベースライン）算出を行い、Datadog 計測値とのクロスバリデーションによって数値の妥当性を検証しました。

#### 主な対応

- Datadog モニター全 55 件の棚卸し・分類（サービス稼働・インフラ・DB・外部依存ビジネス系・業務系など観点別に整理）
- モニター閾値レビューの実施、要対応・要見直し項目の洗い出しとレポート化
- AWS ALB ログ分析によるサービス稼働率 SLI の実測ベースライン算出
- Datadog メトリクスと ALB ログ実測値のクロスバリデーション
- SLO 定義資料（現状把握〜SLI 算出）の作成・整備
- ステークホルダー間の要件調整、資料の平易化・レビュー対応

#### 成果

- Datadog モニター 55 件の分類・整理により、監視の全体像を可視化し改善優先度を明確化
- 閾値・通知経路の不整合を洗い出し、監視精度向上に向けた改善項目を提示
- AWS ALB ログからサービス稼働率 SLI の実測値 99.997％を算出し、Datadog との整合性を検証（現状の実測ベースラインであり、稼働保証や改善成果ではない）
- SLO 定義に必要な現状把握、SLI 算出結果、見直し項目を資料に整理
